## 2025-02-27 - Modernizing pandas iterrows to itertuples
**Learning:** `iterrows` is known to be slow in pandas because it creates a Series for each row. The modern, more performant, and type-preserving alternative is `itertuples`, which yields namedtuples. Since this repository uses pandas DataFrames in its markdown generator scripts and loops over them line-by-line, updating these loops provides an idiomatic speed and memory enhancement. Note that `item.column_name` access works identical in both (`iterrows` returns a pandas Series accessed by property or dict key, `itertuples` returns a namedtuple accessed by property).
**Action:** Replace `for row, item in df.iterrows():` with `for item in df.itertuples():` in Python scripts and their corresponding `.ipynb` notebooks using a script.
