## 2025-06-04 - Logging vs Print in Python Scripts
**Learning:** The `markdown_generator` and `talkmap.py` scripts were using `print()` for debugging and standard output, which is not professional or clean for production-quality codebase environments. Additionally, the `Nominatim` library requires a custom `user_agent` string instead of the default to avoid API ConfigurationErrors.
**Action:** Replaced `print()` with Python's standard `logging` module to allow for proper log levels and structuring. Initialized `Nominatim` with `user_agent="academicpages"`. When replacing multiline text with Python helper scripts, carefully escape string quotes and brackets, or use multiline regex/replace approaches with file reading. Safely get dictionary variables instead of throwing errors if unhandled missing keys occur in logging output.
