## 2025-05-23 - Replacing raw print statements with standard logging format
**Learning:** In data conversion scripts like `markdown_generator/pubsFromBib.py`, replacing raw `print()` statements with standard `logging.info()` or `logging.warning()` improves execution structure and makes it easier to trace conversion errors or parse outcomes without polluting stdout unnecessarily. `import logging` paired with `logging.basicConfig(level=logging.INFO, format='%(levelname)s: %(message)s')` establishes a foundational professional standard.
**Action:** Always replace raw `print` statements with Python's standard `logging` module in data ingestion or generation scripts. Apply similar logging configuration to ensure the output aligns with typical codebase practices for logging parsing errors and successes.
