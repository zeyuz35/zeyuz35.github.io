## 2024-05-18 - Fix XSS Vulnerability in html_escape function
**Vulnerability:** The custom `html_escape` function used across `markdown_generator` scripts and notebooks did not escape `<` and `>` characters, leaving the site vulnerable to XSS attacks from potentially malicious markdown or bibtex inputs.
**Learning:** This function was used in several places to write output for academic pages and it explicitly filtered strings. However, if any user input containing `<` or `>` was passed, those characters would not be properly escaped in the generated HTML/Markdown attributes and content. In addition, the function's strict `type(text) is str` checking caused problems when `None` or other variable types were passed to it.
**Prevention:** Always use comprehensive html escape characters such as `&lt;` and `&gt;` when inserting user input into markdown/html. Ensure utility functions correctly handle unexpected inputs instead of returning unescaped values or returning "False".
