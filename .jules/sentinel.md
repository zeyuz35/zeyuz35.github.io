## 2024-03-06 - Prevent XSS and YAML Injection in Markdown Generators
**Vulnerability:** XSS and YAML Injection vulnerabilities were found in `publications.py`, `talks.py`, and `pubsFromBib.py` because user-controlled inputs (like `title`, `venue`, `url`, etc.) were directly interpolated into YAML front matter and Markdown HTML blocks without escaping. The `html_escape` function also threw errors if non-strings (like NaNs) were passed to it, causing developers to avoid using it everywhere.
**Learning:** Hardcoded text and variables interpolated into Markdown strings (which are later evaluated as YAML and HTML by Jekyll) are vulnerable. The escape function must be robust and safe to call on any data type.
**Prevention:** Always cast inputs to string before iterating over them in an escape function (e.g., `return "".join(html_escape_table.get(c,c) for c in str(text))`). Apply this safe `html_escape` function to ALL user-controlled variables before concatenating them into templates.
