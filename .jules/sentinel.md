## 2025-02-18 - XSS and YAML Injection Vulnerability in Markdown Generators
**Vulnerability:** User-controlled strings, specifically title and other fields from the raw input CSV/BibTeX, were being directly written into YAML front-matter or HTML block links without adequate HTML escaping. The `html_escape_table` missed mappings for `<` and `>`, leading to potential XSS if the generated markdown files were rendered to a web page. In addition, the `html_escape` function was prone to failure if non-string inputs were passed into it.
**Learning:** This codebase lacked comprehensive encoding of generated HTML attributes and YAML metadata values, because escaping was done manually with a simplistic `html_escape_table` which was incomplete.
**Prevention:** Always comprehensively escape or use dedicated templating/escaping libraries instead of manual replacements. The fix updated `html_escape_table` to include `<` and `>`, ensured `str()` casting in the `html_escape` function to prevent attribute errors, and wrapped previously unescaped variables like `title`.
