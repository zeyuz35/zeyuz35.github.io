## 2024-05-01 - Fix XSS Vulnerability in Markdown Generators
**Vulnerability:** The `html_escape` functions in the markdown generation scripts (`markdown_generator/*.py` and `markdown_generator/*.ipynb`) failed to escape `<` and `>` characters, leaving the generated markdown files vulnerable to Cross-Site Scripting (XSS) if they process untrusted TSV or BibTeX input containing raw HTML tags.
**Learning:** The custom `html_escape_table` explicitly handled `&`, `"`, and `'`, but surprisingly omitted the standard `<` and `>` elements which are critical for preventing HTML injection. Because these scripts iterate through user-supplied files (TSV/BibTeX) to build Markdown which can embed HTML, unescaped tags could inject scripts.
**Prevention:** Always ensure custom HTML escaping mechanisms include all critical characters (`&`, `<`, `>`, `"`, `'`). It is safer to use built-in libraries (like `html.escape` in Python) when available, rather than creating custom translation tables.
