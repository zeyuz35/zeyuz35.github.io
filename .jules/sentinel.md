## 2024-04-01 - Fix XSS Vulnerability in Markdown Generators
**Vulnerability:** The `html_escape` function in `markdown_generator/*.py` and `*.ipynb` files did not escape `<` and `>` characters, leading to potential Cross-Site Scripting (XSS) when rendering untrusted BibTeX or TSV fields. Also, `html_escape` failed to handle non-string inputs properly (e.g., throwing exceptions or returning "False" instead of converting to strings), and generated markdown did not include `rel="noopener noreferrer"` for `target="_blank"` links, posing a tabnabbing risk.
**Learning:** Security holes often exist in unmaintained generator scripts which take complex formatting strings. It is critical to sanitize and convert inputs into standard strings correctly before escaping.
**Prevention:** Always use a comprehensive HTML entity map (including `<` and `>`) when parsing unstructured texts. In addition, when adding `target="_blank"` attribute to Markdown or HTML links, always pair it with `rel="noopener noreferrer"`.
