## 2025-03-07 - Prevent XSS and YAML injection in markdown generators
**Vulnerability:** The `html_escape` function used in `markdown_generator/` scripts/notebooks failed to escape `<` and `>` characters and crashed on non-string inputs. This allows Cross-Site Scripting (XSS) and YAML injection when user-supplied strings (titles, descriptions, venues) are placed into generated HTML links or Markdown YAML front-matter blocks.
**Learning:** Python script generated output for Jekyll/Markdown files should proactively handle escaping of all significant characters (`<`, `>`, `&`, `"`, `'`) explicitly and correctly convert types with `str()` to avoid attribute errors or silent XSS insertion vectors during data injection.
**Prevention:** Always ensure complete HTML escaping tables (including `<` and `>`) are used when user inputs are embedded in HTML attributes or output formats, and cast to `str()` when converting to prevent unexpected typing issues causing partial execution or crashes.
