## 2024-05-24 - YAML Injection/XSS in Markdown Generators
**Vulnerability:** User-controlled inputs (title, urls, type, venue) in markdown generators were directly concatenated into YAML front matter and Markdown/HTML link attributes without escaping, allowing for YAML injection and Stored XSS if the TSV source contained malicious payloads. The `html_escape` function also failed on non-string inputs (like integers or NaNs from pandas).
**Learning:** Data extracted via pandas from TSVs or BibTeX files is inherently untrusted, especially since this site generator converts this metadata into Jekyll YAML blocks. Failure to cast fields to strings before iteration in `html_escape()` causes crashes during iteration, and unescaped YAML variables can lead to arbitrary code execution or broken site builds if quotes or special characters aren't sanitized.
**Prevention:** All user-controlled variables inserted into generated markdown must be passed through a robust `html_escape()` function that handles non-string inputs gracefully via `str()`.
