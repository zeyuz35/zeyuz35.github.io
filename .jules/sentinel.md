## 2024-05-18 - XSS Mitigation in Markdown Generators
**Vulnerability:** The custom `html_escape` function used across `markdown_generator/*.py` and `*.ipynb` files replaced `&`, `"`, and `'` but neglected to replace `<` and `>` characters with their HTML encoded equivalents (`&lt;` and `&gt;`). This would allow users to inject arbitrary HTML or script tags into user-controlled YAML front matter attributes and text blocks (e.g., excerpts, titles) which might bypass template sanitization and lead to XSS on the Jekyll site.
**Learning:** Home-rolled sanitization functions frequently miss edge cases or key characters. `<` and `>` are primary components of HTML tags and omitting them leaves a massive hole in XSS defenses. The function also had a type error bug waiting to happen if non-string text was passed.
**Prevention:** Ensure any custom `html_escape` functions cover all relevant HTML special characters, especially `<` and `>`. Alternatively, rely on standard library sanitization features if available. Also, ensure the function handles non-string inputs safely (e.g., by coercing `str(text)`).
