## 2024-05-14 - Replace Pandas iterrows() with itertuples()
**Learning:** The `markdown_generator/` scripts (`publications.py`, `talks.py`) previously used `iterrows()` to iterate over Pandas DataFrames. `iterrows()` is known to be very slow because it returns each row as a Pandas Series, leading to significant overhead, especially for large datasets. Using `itertuples()` is generally 50-100x faster since it returns rows as namedtuples and avoids type-checking overhead. Since the column names in TSV files (`pub_date`, `url_slug`, `title`, etc.) act as valid Python identifiers, transitioning to `itertuples()` was straightforward and required no other downstream logic changes while preserving exact functionality.
**Action:** When working with Pandas DataFrames in this repository, prefer `itertuples()` over `iterrows()` for optimal performance. Ensure column names in CSVs/TSVs are valid Python identifiers to maximize compatibility with namedtuples.
