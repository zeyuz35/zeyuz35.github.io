## 2025-03-04 - Unthrottled DOM Queries on Window Resize
**Learning:** The application was experiencing layout thrashing because it executed expensive DOM queries $('.author__urls.social-icons li') on every single emission of the window.resize event. Synchronous UI calculations on resize significantly block the main thread and degrade rendering performance.
**Action:** Combine all resize-dependent recalculations into a single debounced or throttled loop (e.g., using setInterval with a didResize flag) that evaluates every 200-250ms to prevent CPU spiking during continuous window resizing.
