## 2024-05-24 - Python String Concatenation Bottlenecks in Generator Scripts
**Learning:** In generator scripts (like `pubsFromBib.py` and `PubsFromBib.ipynb`), concatenating strings iteratively within loops (e.g., `citation = citation + ...`) causes O(n²) performance overhead due to Python's immutable strings reallocating memory on every addition. This architecture-specific bottleneck is significant here because the scripts iterate over potentially hundreds of publications/authors to generate static content.
**Action:** When updating or writing static generator scripts in this codebase, always use list appends followed by `"".join(list)` (which is O(n)) for building large text blocks like citations or Markdown files to prevent performance regressions during site builds.
