## YYYY-MM-DD - Replace pandas iterrows with itertuples
**Learning:** `iterrows()` in pandas is relatively slow because it yields a Series for each row. Using `itertuples()` is much faster as it returns a named tuple, especially for simple data iteration loops that don't need Series methods. We can use itertuples() here directly because it returns a namedtuple that retains original column names as attributes, keeping backward compatibility with the `item.date` / `item.title` attribute access format.
**Action:** Replace `for row, item in df.iterrows():` with `for item in df.itertuples():` in `markdown_generator/publications.py`, `markdown_generator/publications.ipynb`, `markdown_generator/talks.py`, and `markdown_generator/talks.ipynb` to improve the performance of TSV processing without sacrificing readability.
