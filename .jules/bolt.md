## 2024-06-15 - Optimize pandas row iteration in Markdown Generators
**Learning:** Found instances where pandas DataFrames were being iterated over using `iterrows()` in `markdown_generator/publications.py`, `markdown_generator/talks.py`, and their respective Jupyter Notebooks. The `iterrows()` function is known to be very slow for large datasets because it yields a Series for each row. Using `itertuples()` is generally 50-100x faster, preserving the same dot-notation access to the data columns, and improving the overall generation speed of the markdown content.
**Action:** Replaced `iterrows()` with `itertuples()` in the python scripts and updated their corresponding Jupyter Notebook source code. Since the index variable `row` was not being used inside the loop, the transition was a drop-in replacement (`for item in df.itertuples():`).
